**（1）制作アプリのタイトル**

Medi-log(メディログ)

**（2）制作アプリの説明（40文字程度）**

メディログは服薬支援を行うためのアプリ（今のところページ）です。

常用薬やサプリメントの服薬管理を簡単に行うことができます。服用する本人や介助者が薬を適切に飲むことができたかわかるように記録できます。

あらかじめ服用期間を設定しておくことで、診察時の残薬調整をスマートに行う事ができ、医療資源を適正化に寄与します。

服薬管理アプリはいくつかありますが、シンプルなものがなく、無駄な機能がついているものや企業タイアップがわずらわしいのでシンプルで簡単に使用できるものを自分で設計してみました。

**（3）工夫した点・こだわった点**
ユーザーの認知不可がかからないようにイメージを膨らませながらデザイン設計しました。

日付を押したときの動き(Accordion)や、薬追加アイコンを押下したときの動き(Bottom Sheet)などを使って、ページを遷移させることなく一つのカレンダーの上ですべてが完結しているように見えるように工夫しました。

**（4）難しかった点・次回トライしたいこと（または機能）**
そもそもカレンダーを作ることに苦戦しました。色々調べて先人の知恵をたくさん借りました。2000年問題とか大変だったんだなとあらためて思いました。

今回はデータベースを使用していないので、デモデータでとりあえず使用感がわかるサンプルを作成しました。

データベースがあれば医薬品や用法のマスタ、個人ごとのログの管理などが可能になると思われるので需要があれば実装してみたい。

また、webベースの先にアプリケーションへの昇華が可能なレイアウトにしているので、その場合はスマホの通知に連動した服用アラームなどの機能を入れてみたい。
