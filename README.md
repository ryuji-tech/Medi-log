**（2）制作アプリの説明（40文字程度）**

メディログは服薬支援を行うためのアプリ（今のところページ）です。

常用薬やサプリメント、健康食品の服薬管理を簡単に行うことができます。服用する本人や介助者、家族の服薬記録などの情報を適切に記録できます。

あらかじめ服用期間を設定し薬の残薬が把握しておくことで、診察時の残薬調整をスマートにし医療資源を適正化に寄与します。

また、現行版では既往歴やアレルギー歴、ワクチン接種歴などの管理も可能となり、いざというときに必要な薬以外の過去の情報も素早く確認することができるようになりました。

**（3）工夫した点・こだわった点**

旧版としてlocalStorageを用いたバージョンを作成し、今回は発展形としてFirebaseによるデータベース管理に移行しました。

レイアウトはlocalStorage版である程度形作っていたので今回はデザインを重点的に見直しました。（…見直したというかこれまで時間がなくて仮のデザインでしのいでいたので当初から頭の中でイメージしたデザインに変更しました。）

前回からのアップデートとして、アカウント認証と既往やアレルギー、予防接種歴の管理などを行う機能を追加し、より医療機関受診時の問診に概ね適応する形に仕上げました。

別のアカウントを友達追加することで、追加したアカウントの情報も閲覧できます。（家族や施設内での情報管理に役立ちます）

アカウントの名称を拾うので、友達追加した際に見られても困らない名称に自身のアカウント表示名を変更できる機能もつけました。

とりあえず何を一番こだわったいえばデザインです。もともとこのデザインで何かプロダクトを作ってみたかったので、今回はそれをこのアプリにぶつけてみました。

**（4）難しかった点・次回トライしたいこと（または機能）**

アラート機能や文字表示の大きさの切り替え、アカウントごとのテーマカラーの変更などを検討。現在はWEBベースだがアプリ版も作成してみたい。

**（5）備考（感想、シェアしたいこと等なんでも）**

今回Firebaseでのデプロイ後にスマートフォンで動作確認を行いました。検証ツールのスマートフォンサイズではうまく表示されている場合でも、実機ではレイアウトが乱れていることも多かった。また、複数のブラウザによる動作確認も行ってみたところ、アラートやトーストがデフォルトの機能と干渉してうまく表示されずに意図した機能がうまく使えなくなるブラウザも存在することがわかりました。最終的に確認等のアラートはすべてモーダルに統一することでブラウザが変わっても同じ動きをするように実現しました。

OSにデフォルトで入っているデザインが邪魔してレイアウトが崩れる状況を直していく作業が地味に面倒だった。（iPhoneの洗練されたデザインは好きである一方、）せっかくPC上できれいに表示されている自分のデザインをiPhoneのデフォルトデザインがいちいち邪魔してきたので少し楯突くことにした。スマートフォンでも自身のデザインがきれいに表示されるようにところどころ思い切ってデフォルトの表示スタイルを取り消して自身のデザインを強制的に当てはめる取り組みをした。（-webkit-appearance: noneでデフォルトスタイルを削除してAppleデザインに宣戦布告できる）

**■ セットアップ（Firebase版をローカルで動かす場合）**

Firebaseの接続情報は `js/firebase-config.js` に置いていますが、このファイルはAPIキーを含むため `.gitignore` で除外しており、リポジトリには含まれていません。クローン後は以下の手順で作成してください。

1. テンプレート `js/firebase-config.example.js` を同じ階層にコピーし、`js/firebase-config.js` という名前にする
2. コピーした `js/firebase-config.js` を開き、自分のFirebaseプロジェクトの値（apiKey / authDomain / projectId など）を各項目に設定する

`js/app.js` はこの `firebase-config.js` から設定を `import` して起動するため、ファイルが無いと動作しません。

>※実際のアクセス制御はFirestoreのセキュリティルール（`firestore.rules`）で行っています。
